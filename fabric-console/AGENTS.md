# Console rules

- This is Sathonate's React/TypeScript application; Go backend is a separate repository at E:/Sathonate/fabric-control-plane.
- Use versioned HTTP API calls; never import files from the backend repository.
- Make network design understandable without YAML. Keep advanced references in progressive disclosures.
- Drafts, plans and actual deployed state must have distinct labels. Never simulate provisioning success or live metrics.
- Do not collect passwords or private keys in configuration forms.
- Support keyboard navigation, labels, loading/error/empty states and mobile widths.
- Build and test before delivery. Keep package-lock.json committed when committing dependency changes.
